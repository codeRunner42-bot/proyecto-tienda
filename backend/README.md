# Backend

Este directorio contiene el servidor Express y los datos.

- `server.js`: servidor con API REST para productos y pedidos.
- `products.json`: lista de productos.
- `orders.json`: pedidos creados por los clientes.
- `package.json`: dependencias y comando `npm start`.

## Ejecutar

```bash
cd pagina/backend
npm install
npm start
```

Luego abre `http://localhost:3000/`.
