# Frontend

Este directorio contiene la interfaz de la tienda:

- `index.html`
- `cart.html`
- `checkout.html`
- `admin.html`
- `admin-orders.html`
- `assets/`

El frontend consume la API del backend en `/api/products` y `/api/orders`.

No sirvas estos archivos directamente con un servidor estático diferente al backend. Usa el backend para que las rutas funcionen correctamente.
